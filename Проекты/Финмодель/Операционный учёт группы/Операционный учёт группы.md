# Операционный учёт группы

## Описание

Финансовая модель группы из 3 юрлиц (Транзит, Северный Путь, Инком Транс) на базе операционного отчёта «Интеркомпани». Задача — построить БДР и БДДС по месяцам, начиная с Q3 2026 (июль-август-сентябрь), для последующего планирования Q4 и далее.

## Цель проекта

Дать Павлу **единый управленческий взгляд** на прибыльность и денежный поток группы, устранив искажения от того, что клиенты «раскидывают» платежи между ЮЛ по своим налоговым причинам, а расходы часто несёт одно ЮЛ (обычно СП).

## Ключевые результаты

1. **Методология БДР/БДДС** — принята и зафиксирована (см. `01_Методология/`)
2. **Справочники** — статьи БДР, статьи БДДС, маппинг колонок «Интеркомпани» → статьи (см. `02_Справочники/`)
3. **Факт Q3 2026** — БДР и БДДС по 3 ЮЛ + консолидированный, июль/август/сентябрь (см. `03_Факт_2026_Q3/`)
4. **Показатель «выпадающая выручка на СП»** — считается ежемесячно, видна к «искусственному закрытию»
5. **План Q4 2026** — в той же форме (см. `04_План_Q4_2026/`)
6. **Скрипт автозагрузки** xlsx «Интеркомпани» → БДР (см. `05_Скрипты/`)

## Ключевые решения (методология)

### Консолидация
- **Управленческий подход, не МСФО** — консолидированный БДР = арифметическая сумма 3 ЮЛ
- Интеркомпани **не элиминируем**: почти все обороты внешние, единственная реально внутренняя услуга «Предоставление вагона» (ИТ → СП) — оставляем как есть
- Отдельные БДР по ЮЛ — **справочно** (цифры искажены из-за раскидки платежей клиентами)
- **Реальный P&L группы = консолидированный** (по нему принимаем решения)

### БДДС
- **По месяцам, без сроков оплаты** (не даты платежей — а факт месяца)
- **По каждому ЮЛ** отдельно + консолидированный
- Отдельная строка «Выпадающая выручка на СП» = сумма, которую клиент заплатил на Транзит/ИТ, но расходы понёс СП
- Эта строка закрывается **«искусственным оборотом»** — внутригрупповая переброска денег между ЮЛ

### Расчёт «выпадающей выручки на СП»
- **Комбинированный:** метод A (по рейсам, точный) + метод B (по итогам ЮЛ, индикатор)
- Метод A даёт цифру для «искусственного закрытия» (см. `01_Методология/03 Выпадающая выручка.md`)

## Риски

1. **Данные Q3 неполные** — если июль/сентябрь придут в другом формате xlsx
2. **Валютные пересчёты** — курс USD/RUB на дату каждого рейса нужен (сейчас используем средний за месяц)
3. **Дублирование затрат** — если в отчёте «Интеркомпани» есть строки, где расход дублируется на 2 ЮЛ
4. **БДДС ≠ БДР** — этот проект строит БДДС аналитически из БДР (без банковских выписок); реальный кэш-флоу может отличаться
5. **Раскидка платежей клиентом** — методика фиксации «выпадающей выручки» требует утверждения на нескольких кейсах
