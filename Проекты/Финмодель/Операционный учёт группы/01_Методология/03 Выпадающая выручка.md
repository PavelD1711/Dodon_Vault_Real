# Выпадающая выручка на СП — методология

## Определение

**Выпадающая выручка на ЮЛ = сумма, которую ЮЛ «должно было бы получить» за понесённые им расходы, но выручка ушла на другое ЮЛ группы.**

Чаще всего страдает **СП** (Северный Путь), потому что он несёт наибольший объём операционных расходов (тарифы, аренда вагонов), а клиенты «раскидывают» платежи на Транзит и Инком Транс.

## Зачем считаем

1. **Видеть реальную боль СП** — если у него минус, это не убыток бизнеса, а «неполученная выручка»
2. **Планировать закрывающие переброски** — по итогам месяца провести внутригрупповой платёж (Транзит/ИТ → СП) на эту сумму
3. **Не показывать «фейковый убыток»** внешним пользователям (банки, налоговая) — использовать закрывающие операции

## Два метода расчёта (используем оба)

### Метод A. По рейсам (точный)

**Алгоритм:**
1. Проходим по каждому рейсу в файле «Интеркомпани»
2. Для рейса определяем:
   - `costs_СП` = сумма всех столбцов затрат, где `Организация затрат = Северный Путь`
   - `revenue_СП` = Продажа 1 + Продажа 3, где `Организация реализации = Северный Путь`
   - `revenue_others` = Продажа 1 + Продажа 3, где организация ≠ СП (то есть Транзит или ИТ или пусто)
3. **Если** `costs_СП > 0` **и** `revenue_others > 0`:
   - Считаем, что СП понёс расходы, а часть выручки ушла на другое ЮЛ
   - **Выпадающая для СП по рейсу = revenue_others** (тот кусок, который «мог бы быть» у СП)
4. Сумма по всем рейсам за месяц = **общая выпадающая выручка СП за месяц**

**Пример (август, 73 рейса ARTCOMMERCE):**
- СП несёт: Тариф РФ, Транзит КЗХ, Предоставление вагона (~700-900 тыс RUB/рейс)
- Клиент ARTCOMMERCE платит: Продажа 1 «Транзит» = 317 000 RUB/рейс (на СП/Транзит) + Продажа 3 «Северный Путь» = 4 500 USD/рейс
- **Ключ:** в 73 рейсах ARTCOMMERCE Продажа 1 идёт на «Транзит» (RUB), а расходы — на СП
- Выпадающая = 317 000 × 73 = **23,1 млн RUB** для СП только по ARTCOMMERCE

### Метод B. По итогам ЮЛ (индикатор)

**Алгоритм:**
1. Строим БДР СП
2. Смотрим валовую прибыль СП: если минус — это индикатор «плохого» месяца или большой выпадающей
3. Сравниваем с Транзитом и ИТ: у одного из них должна быть неоправданно высокая маржа

**Формула:**
```
индикатор_выпадающей_СП = (валовая_маржа_группы / выручка_группы) × выручка_СП − валовая_прибыль_СП
```

То есть: «если бы у СП была средняя маржа группы, какой должна быть его валовая прибыль. Разница с фактом = сколько «не хватает» СП».

## Различия A и B

| Метод | Точность | Скорость | Использование |
|---|---|---|---|
| A. По рейсам | Высокая | Медленная (нужно пройти все строки) | **Для «закрывающих переброс.»** — точная сумма |
| B. По итогам | Средняя | Быстрая | **Индикатор** — «есть ли проблема этот месяц» |

## Действие по итогу месяца

1. Считаем **выпадающую по методу A** (точная сумма)
2. Проводим **внутригрупповой платёж**: Транзит и/или ИТ переводят СП сумму выпадающей выручки
3. Эта операция отражается в **БДДС** как:
   - У Транзит/ИТ: отток «Своим ЮЛ (интеркомпани)»
   - У СП: приток «От своих ЮЛ (интеркомпани)»
4. **В БДР эта операция НЕ отражается** — это не доход/расход, а внутригрупповая переброска

## Отчёт по выпадающей выручке (формат)

```
Выпадающая выручка на СП — август 2026
═════════════════════════════════════════════
Метод A (точный):
  По рейсам ARTCOMMERCE:      X млн RUB
  По рейсам Байэл Строй:      X млн RUB
  По другим клиентам:         X млн RUB
  ──────────────────────────────────────────
  Итого выпадающая на СП:     X млн RUB

Метод B (индикатор):
  Средняя маржа группы:       X %
  Ожидаемая ВП СП:            X млн RUB
  Фактическая ВП СП:          X млн RUB
  Индикатор:                  X млн RUB

Рекомендация:
  Провести переброску: Транзит → СП X млн RUB
                       ИТ → СП X млн RUB
═════════════════════════════════════════════
```

## Пропорция распределения переброски (Транзит vs ИТ)

По умолчанию — **пропорционально выручке**, полученной каждым из них от рейсов, где расходы нёс СП.

Это можно уточнить с Павлом (может быть отдельное правило по договорённости между ЮЛ).
