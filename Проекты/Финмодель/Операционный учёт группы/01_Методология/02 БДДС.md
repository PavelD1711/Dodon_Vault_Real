# БДДС — методология

## Ключевое отличие от БДР

- **БДР** — начислено (доход/расход по факту оказания услуги)
- **БДДС** — фактическое движение денег (в этом проекте v0.1 — **упрощённо, по месяцам, без сроков оплаты**)

## v0.1 упрощение

Мы **не работаем с датами оплаты** в первой версии. Считаем:
- **Приход БДДС месяца** = сумма выручки, оформленной на ЮЛ в этом месяце (по «Организации реализации»)
- **Расход БДДС месяца** = сумма затрат, оформленной на ЮЛ в этом месяце (по «Организации затрат»)

То есть **БДДС = БДР без разделения «начислено/оплачено»**. Это временно, до тех пор пока нет банковских выписок или 1С «Движение ДС».

⚠️ **Погрешность:** реальный кэш-флоу может отличаться из-за:
- Отсрочек оплаты клиентами
- Предоплат
- Задержек оплаты РЖД / собственникам вагонов

Когда Павел даст банковские выписки — построим точный БДДС.

## Форма БДДС (шаблон)

```
БДДС август 2026
═══════════════════════════════════════════
                                Транзит    СП        ИТ        Итого
ПРИТОК ДС
  От клиентов (Продажа 1)       X          X         X         X
  От клиентов (Продажа 3)       X          X         X         X
  От своих ЮЛ (интеркомпани)    X          X         X         X
  ────────────────────────────────────────────────────────────────
  Итого приток                  X          X         X         X

ОТТОК ДС
  Оплата РЖД (Тариф РФ)         X          X         X         X
  Оплата КЗХ (Транзит)          X          X         X         X
  Аренда вагонов                X          X         X         X
  Прочие прямые                 X          X         X         X
  Своим ЮЛ (интеркомпани)       X          X         X         X
  ────────────────────────────────────────────────────────────────
  Итого отток                   X          X         X         X

ЧИСТЫЙ ДС (приток − отток)      X          X         X         X

* Выпадающая выручка на СП       —          Y         —         —
(справочно, см. отдельный отчёт)
═══════════════════════════════════════════
```

## Строка «Выпадающая выручка на СП»

- **НЕ включается в основной БДДС** (это управленческий индикатор, а не денежная операция)
- Отражается **справочно** под таблицей
- Отдельный отчёт: `03 Выпадающая выручка.md` — методика расчёта
- «Закрытие искусственными оборотами» → это уже **отдельные внутригрупповые платежи**, которые Павел проводит по факту → они появляются в БДДС как «От своих ЮЛ / Своим ЮЛ»

## Что НЕ входит в БДДС v0.1

- Налоги (НДС к уплате/возмещению, налог на прибыль) — их надо добавить в v0.2
- ФОТ (зарплаты) — надо добавить в v0.2
- Прочие управленческие расходы — v0.2
- Кредиты / займы / дивиденды — v0.2

**v0.1 фокус:** операционный кэш-флоу от рейсов, максимально быстро и точно.
