# Концепция валютного учёта v1.0

**Группа:** ООО «Инком Транс» + ООО «Северный Путь» + ООО «Транзит»
**Утверждена:** 28.04.2026
**Импорт из Google Doc:** 08.09.2026

> Документ используется как: (1) основа для управленческой отчётности P&L / Баланс / CF, (2) ТЗ для автоматизации учёта, (3) регламент для сотрудников оформляющих валютные сделки.

## 1. Ключевые понятия

### 1.1. Валютный резерв
Неснижаемый остаток в USD, распределён по счетам трёх ЮЛ. Совокупный резерв группы: **~$300 000** (пример). Используется для оперативного управления валютной позицией — продажи избытка и покупки дефицита при оформлении каждой заявки.

### 1.2. Два типа курса

**КУРС 1 — Курс сделки (операционный):**
Курс, по которому фактически проводится покупка/продажа валюты на банковском счёте. Фиксируется **в день согласования заявки** — в тот же день совершается валютная операция. Используется в: реестре заявок, P&L, расчёте маржи по сделке.

**КУРС 2 — Балансовый курс (фиксированный):**
Единый курс, устанавливаемый **на квартал** (или отчётный период). Не меняется от месяца к месяцу. Используется для: оценки $ на балансе (резервы, ДЗ, КЗ), расчёта капитала в рублях. Изменяется только при смене отчётного периода — осознанно, вручную.

### 1.3. Реализованная курсовая разница
Разница между курсом сделки и балансовым курсом. **Выделяется отдельной строкой в P&L** — не смешивается с операционной маржой.

```
Курсовая разница = (Курс сделки − Балансовый курс) × Объём $
```

## 2. Принцип управления валютной позицией

При получении каждой подтверждённой заявки:

**ШАГ 1. Рассчитать валютную позицию:**
```
Позиция = Резерв + Будущие доходы в $ − Будущие расходы в $ − Дефицит по ₽-клиентам
```

**ШАГ 2. Определить действие:**
- Позиция **> 0** (избыток) → **ПРОДАТЬ** излишек $ в тот же день по курсу банка
- Позиция **< 0** (дефицит) → **ДОКУПИТЬ** недостающие $ в тот же день по курсу банка
- Позиция **= 0** → ничего не делать

**ШАГ 3.** Зафиксировать курс сделки в реестре заявок.

**ШАГ 4.** При срыве заявки клиентом — взыскать штраф по формуле:
```
Штраф = (Курс на дату срыва − Курс на дату продажи) × Объём проданных $
```

## 3. Примеры

### 3.1. ПРИМЕР А — USD-клиент

**Условие:**
- Резерв группы: $300 000
- Заявка: 10 вагонов, Москва → Ташкент
- Ставка: $9 000/вагон → Доход $90 000
- Расход (транзит КЗ): $4 000/вагон → Расход $40 000
- Рублёвые расходы (аренда ПС): 3 500 000 ₽ (≈ $38 889 по балансовому курсу 90)
- Балансовый курс: 90 руб./$
- Курс сделки: 90,50 руб./$

**Расчёт позиции:**
```
$300 000 (резерв) + $90 000 (доход) − $40 000 (КЗ транзит) − $38 889 (руб.≈$) = +$111 111
```

**Действие:** ПРОДАТЬ $111 111 по курсу 90,50.

**P&L (по курсу сделки 90,50):**
| Строка | ₽ |
|---|---|
| Доход $90 000 × 90,50 | 8 145 000 |
| Расход КЗ $40 000 × 90,50 | −3 620 000 |
| Расход аренды (₽) | −3 500 000 |
| **Валовая прибыль** | **1 025 000** |
| Курсовая разница ($50 000 × 0,50) | +25 000 |

**Баланс (по балансовому 90,00):**
Резерв после продажи: $300 000 + $90 000 − $40 000 − $111 111 = **$238 889** = 21 500 010 ₽

### 3.2. ПРИМЕР Б — ₽-клиент с $-расходами

**Условие:**
- Резерв: $300 000
- Заявка: 5 вагонов, Москва → Баку
- Ставка клиента: 400 000 ₽/вагон → Доход 2 000 000 ₽
- Расход (транзит): $3 500/вагон → Расход $17 500
- Балансовый курс: 90 / Курс сделки: 91,00

**Расчёт позиции:**
```
$300 000 − $17 500 = $282 500 → в плюсе, резерва хватает
```

**Действие:** Ничего не покупаем — КЗ закрывается из резерва.

**P&L (расходы по курсу сделки 91):**
- Доход: 2 000 000 ₽
- Расход КЗ: $17 500 × 91,00 = 1 592 500 ₽
- **Валовая прибыль: 407 500 ₽**
- Курсовая разница: $17 500 × (91 − 90) = 17 500 ₽ (расход — оцениваем дороже, чем по балансу)

### 3.3. ПРИМЕР В — Срыв заявки

Продали $50 000 по 90,50 (ПРИМЕР-001). Клиент срывает. Курс на дату срыва — 92,00.

```
Штраф = (92,00 − 90,50) × $50 000 = 1,50 × $50 000 = 75 000 ₽
```

## 4. Сводная таблица правил учёта

| Что учитываем | Курс | Где отражается |
|---|---|---|
| P&L: доходы и расходы по сделке | Курс сделки (день согласования) | P&L ЮЛ + направления |
| Баланс: $ на счетах (резервы, ДЗ, КЗ) | Балансовый курс периода | Баланс каждого ЮЛ |
| Реализованная курсовая разница | (Курс сделки − Балансовый) × Объём $ | Отдельная строка P&L |
| Штраф при срыве заявки | (Курс срыва − Курс продажи) × Объём $ | Прочие доходы P&L |

## 5. Требования к автоматизации

**Хранить по каждой заявке:**
- Дата согласования
- Курс сделки (вручную или через API банка)
- Объём $ (доход + расход)
- Валюта оплаты клиента (USD / RUB)
- ЮЛ-исполнитель

**Автоматически рассчитывать:**
- Валютную позицию группы после каждой заявки
- Рекомендуемое действие (купить/продать $ и сколько)
- Рублёвый эквивалент операций (по курсу сделки)
- Реализованную курсовую разницу

**Балансовый курс:**
- Единый параметр системы
- Менять только при смене отчётного периода
- Версионировать (дата начала/окончания)

**Отчётность:**
- P&L по ЮЛ и направлениям — с выделенной строкой курсовой разницы
- Баланс — $ по балансовому курсу
- Реестр валютных операций (дата, объём, курс, ЮЛ, заявка)
