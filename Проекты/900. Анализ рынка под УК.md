# 900. Анализ рынка под УК

## Суть проекта

Модель УК (управляющая компания вагонным парком):
- Берём вагоны **не в аренду**, а под **оперативное управление**
- Фокус: небольшие компании-собственники **до 700 вагонов**
- Условия: фикс за управление (возможно + ремонты) + сверхдоход выше базовой доходности делим с собственником

## Задача проекта

1. Понять — есть ли потенциал в этой модели
2. Сколько таких вагонов можно найти на рынке
3. Сформировать воронку потенциальных собственников
4. Оценить ёмкость → решение по ДК ОБ
