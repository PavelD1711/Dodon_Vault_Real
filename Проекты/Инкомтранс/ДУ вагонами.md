# ДУ вагонами — доверительное управление вместо аренды

**Гипотеза Павла (15.09.2026):** предложить рынку альтернативу аренде — модель **доверительного управления** вагонами. ИТ не арендует у собственника, а становится доверительным управляющим его парка.

## Суть модели

### Как сейчас (аренда)
Собственник → **аренда** → оператор
- Собственник получает **фиксированную ставку**, вне зависимости от результата
- Оператор берёт весь риск и весь апсайд
- Оператор не заинтересован показывать реальную экономику

### Что предлагаем (ДУ)
Собственник → **доверительное управление** → ИТ
- Собственник получает **долю от финансового результата** вагона
- ИТ не платит фикс, зарабатывает свою долю
- Оба разделяют риск и апсайд
- Прозрачность экономики — обязательное условие модели

## Почему это может выстрелить

### 🟢 Плюсы для собственника
1. **Апсайд при росте рынка** — сейчас на растущем рынке собственник ничего не получает сверх аренды
2. **Оператор мотивирован** — его доля зависит от результата, значит будет выжимать по максимуму
3. **Психологически:** «мои вагоны работают на меня», а не «переуступлены дяде»
4. **Налоги/структуринг:** ДУ регулируется главой 53 ГК + гл. 25 НК — свои преимущества по НДС и налогу на прибыль

### 🟢 Плюсы для Инкомтранса
1. **Расширение парка без CAPEX и без арендных обязательств** — расход только когда вагон приносит доход
2. **Дифференциация продукта** — на рынке 95% работают через аренду
3. **Привлекает вагоны от собственников, которые НЕ хотят сдавать в аренду**
4. **Высокая маржа при удачном рынке** — 25-40% от результата без фикс-платежа
5. **Стратегическое преимущество против ЦО** — прямо противоположная модель обезличенному распределению

### 🔴 Риски и слабые места

1. **Кассовый риск для собственника.**
   Аренда — предсказуемо. ДУ — плавает. Если у собственника лизинг с фиксом — страшно отказаться от гарантии.
   → **Решение:** гибрид «флор + доля» (гарантированный минимум + процент сверху)

2. **Юридическая сложность.**
   - Договор ДУ — не аренда, регистрация обременения по каждому вагону в ЭТРАН
   - Раздельный учёт по каждому доверителю
   - Обязательная отчётность собственнику
   - Ответственность ДУ управляющего выше — «действовать в интересах доверителя»
   → **Решение:** типовой договор + отдельная функция бэк-офиса

3. **Налоговые сюрпризы.**
   - ДУ управляющий — налоговый агент
   - НДС по услугам ДУ — отдельные правила
   - Если собственник физлицо — схема сложнее
   → **Решение:** проработать с Кимом+Ариной заранее

4. **Прозрачность = уязвимость.**
   Собственник имеет право видеть всю экономику. Не все операторы к этому готовы.
   → **Вопрос к Павлу (открытый):** готовы ли показывать полную прозрачность?

5. **Реакция крупных собственников.**
   Крупные лизинги, ПГК выстроены под аренду и скорее всего не пойдут. Целевая аудитория — **средние и небольшие собственники + узкие лизинги**.

6. **Управленческая нагрузка.**
   ДУ = больше отчётности, больше бэк-офиса. Оценить: выигрыш в марже покрывает ли прирост затрат на администрирование?

## Три возможные структуры ДУ

| Модель | Собственник получает | ИТ получает | Кому подходит |
|---|---|---|---|
| **Чистый ДУ** | 100% результата минус доля управляющего | % от результата (25-40%) | Оптимисты по рынку |
| **Гибрид «флор + доля»** | Гарантированный минимум + доля сверх флора | Часть флора + доля | Консервативные + под лизинги |
| **Управляющий за фикс** | Всё сверху минус фикс | Фикс-фи за услугу | Собственник хочет полный апсайд |

## Экономика (гипотетические цифры, требуют проверки)

Один крытый вагон в мес:

| Метрика | Аренда | ДУ (гипотеза) |
|---|---|---|
| Доход валовый | 250-350 т₽ | 250-350 т₽ |
| Собственник | 130-180 т₽ (фикс) | 60-70% от ЧП = 90-160 т₽ |
| ИТ маржа | 20-40 т₽ | 30-70 т₽ (на хорошем рынке) |
| Собственник в апсайде? | Нет | Да |
| ИТ несёт риск простоя? | Да | Разделяет |
| Кассовый расход ИТ | 130-180 т₽ | 0 |

⚠️ **Все цифры — предварительные, требуют проверки на реальных данных.**

## Оценка гипотезы (моя, Pablo)

**7-8 из 10.**

**+** Продукт с реальной болью на рынке
**+** Дифференциация против ЦО и обычных операторов
**+** Совпадает со стратегическим направлением «уход вверх»
**+** Синергия с Северным Путём: «Мы управляем вашими вагонами + продаём вашу перевозку клиенту» — комплексный сервис

**−** Юр/налоговая сложность высокая
**−** Целевая аудитория — не крупные лизинги
**−** Требует ИТ-инфраструктуру для отчётности собственнику
