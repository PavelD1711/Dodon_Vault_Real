# Клиенты FCA — самовывоз / трейдеры

> Клиенты, работающие на условиях FCA: забирают вагоны сами или действуют как трейдеры/перекупщики.

## Отличие от основной базы

| Параметр | Обычный клиент | FCA-клиент |
|----------|---------------|------------|
| Кто подаёт заявку | Грузоотправитель напрямую | Трейдер / экспедитор |
| Доступ к конечному грузоотправителю | Прямой | Через посредника |
| Ценообразование | Рыночный чек | FCA-условия (ниже) |
| Приоритет проработки | Высокий | Средний (зависит от объёма) |

## Реестр (Dataview)

```dataview
TABLE
  статус as "Статус",
  дорога as "Дорога",
  ответственный as "Менеджер",
  объём_рейсов_мес as "Рейсов/мес",
  ожидаемые_заявки_мес as "Заявки (план)",
  категория as "Кат",
  дата_обновления as "Обновлено"
FROM "Проекты/Инкомтранс/Клиентская база/Клиенты FCA"
WHERE file.name != "README"
SORT дорога ASC, объём_рейсов_мес DESC
```
