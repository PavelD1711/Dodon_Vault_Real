# Клиентская база — Инкомтранс

> Досье по всем клиентам: текущим, потенциальным, потерянным.

## Структура

```
Клиентская база/
├── README.md          ← этот файл (реестр через DB Folder)
├── Шаблоны/
│   └── Досье клиента.md
└── Клиенты/
    ├── МСК-001 — Название.md
    ├── КЗХ-001 — Название.md
    └── ...
```

## Статусы клиента

| Статус | Описание |
|--------|----------|
| 🟡 потенциальный | Есть в статистике РЖД, контакта не было |
| 🔵 целевой | Определён как приоритет, в работе у менеджера |
| 🟢 активный | Действующий договор, заявки идут |
| ⏸ приостановлен | Договор есть, заявок нет временно |
| 🔴 расторгнут | Договор расторгнут |
| ⚫ потерян | Работает с конкурентом, недоступен |

## Реестр (DB Folder)

```dataview
TABLE
  статус as "Статус",
  дорога as "Дорога",
  ответственный as "Менеджер",
  объём_рейсов_мес as "Рейсов/мес",
  ожидаемые_заявки_мес as "Заявки (план)",
  вероятность_договора as "Вероятность %",
  дата_обновления as "Обновлено"
FROM "Проекты/Инкомтранс/Клиентская база/Клиенты"
SORT статус ASC, дорога ASC
```
