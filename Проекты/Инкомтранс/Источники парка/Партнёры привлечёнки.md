# Партнёры привлечёнки

~30-40 операторов, у которых ИТ/СП привлекает вагоны на конкретные рейсы (когда своего парка не хватает).

**Владелец процесса:** Аня Сухова (руководитель отдела обеспечения технических рейсов).

## Процесс работы (18 шагов, со слов Ани)

Запрос → Расчёт ставки → Согласование → Обеспечение → Подтверждение → Реквизиты → Распределение → Заявление → Контроль движения → Годность → Погрузка → Отправка → Груженый контроль → Выгрузка → Порожним → Закрытие → НДС

**Приоритет:** аренда своего парка > привлечёнка.

**Порог маржинальности:** был 15% → сейчас растёт до 30%.

**Оплата:** за рейс, не аренда. Предоплата базово. Есть отсрочки и ретро-бонусы — устно или письменно.

- Недобросовестность
- Неприемлемые условия

- Вывод парка

## Инструменты

- **1С WTD** — привлечёнка вносится в **STG** (выбивается из процесса)
- **STG** — учёт привлечённых вагонов, подвязка к заявкам в Алгоритме
- **Excel/Google таблицы** — оперативно, кто чем работает

⚠️ **Боль:** дублирование данных 1С → STG → Алгоритм; работа с привлечёнкой в STG **ещё не готова**.
