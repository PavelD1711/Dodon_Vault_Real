# Источники парка — Инкомтранс

Карта откуда у ИТ берутся вагоны в оперирование.

## Общая цифра

- **~430 крытых вагонов** в управлении (на март 2026, дата уточнить)
- Модель: **долгосрочная аренда у собственников** (не свой парк)
- Заработок: разница между ставкой аренды (input) и ставкой клиенту (output) + операционная эффективность

## Два потока

### 1. Основной парк — долгосрочная аренда (~430 крытых)

**Модель:** ИТ арендует у собственников на длинный контракт → оперирует под своим ЛК.

**Кто собственники этих 430** — ⚠️ **не зафиксировано**, надо заполнить.
Гипотетические категории:
- Лизинговые компании (в т.ч. специализированные на крытых)
- Физлица через лизинги
- Крупные собственники (ФГК, УВЗ-Логистик, СГ-транс?)
- Небольшие частные владельцы

→ [[Собственники парка]] — детальная раскладка (заполняется)

### 2. Привлечёнка (разовые/сессионные рейсы)

**Модель:** для конкретной клиентской заявки, когда своих вагонов не хватает.

**Отвечает:** Аня Сухова (руководитель отдела обеспечения технических рейсов).

**Партнёры (~30-40 договоров):** УТК, РСТ, Атлант (доступ к парку ПГК), ПТА, Евросип. Прямого договора с ПГК нет.

**Приоритет:** аренда собственного парка > привлечёнка (если свой вагон подходит).

**Порог маржинальности:** был 15% → сейчас растёт до 30%.

**Оплата:** за рейс, не аренда. Предоплата базово.

→ [[Партнёры привлечёнки]] — детальная раскладка (заполняется)

### 3. Аутсорсинг логистики (Северный Путь, новое направление)

**Модель:** СП сам становится грузоотправителем, привлекает вагоны у ИТ + сторонних операторов, продаёт клиенту комплексный сервис.

**Отвечает:** Костя Фурсов (операционный руководитель).

**Статус:** 2 действующих клиента, направление после ухода прежних специалистов «в подвешенном состоянии».

→ [[Аутсорсинг логистики]] — детальная раскладка (заполняется)

## Схема

```
                  СОБСТВЕННИКИ ВАГОНОВ
                    (лизинги, ФГК, ?)
                          │
                          │  долгосрочная аренда
                          ▼
                  ┌───────────────────┐
                  │  ИНКОМТРАНС       │  ← 430 крытых
                  │  (оператор)       │  свой парк
                  └─────┬─────────────┘
                        │
                        ├──── прямые клиенты (грузоотправители)
                        │
                        ├──── СЕВЕРНЫЙ ПУТЬ (экспедитор)
                        │     — берёт вагоны у ИТ + добавляет сервис
                        │
    ┌───────────────────┼──────────────────┐
    │                   │                  │
    ▼                   ▼                  ▼
СОБСТВЕННЫЙ ПАРК   ПРИВЛЕЧЁНКА       АУТСОРСИНГ ЛОГИСТИКИ
  (430 крытых)     (рейс операторов)  (Фурсов — новое)
                   УТК, РСТ, Атлант,
                   ПТА, Евросип
                   (~30-40 партнёров)
```

## Открытые вопросы (пробелы в данных)

1. **Раскладка 430 по собственникам** — от кого сколько, ставки, сроки договоров
2. **Динамика парка** — 430 сейчас: рост / стабильно / снижение? Что было 6 и 12 мес назад?
3. **Свой vs привлечёнка** — соотношение по рейсам и по выручке за 2025-2026
4. **Средняя ставка аренды входящая** (что платим собственнику)
5. **Средняя ставка выходящая** (что берём с клиента)
6. **Простои** — доля работающего парка vs стоящий
7. **Структура договоров аренды** (тип, срок, штрафы, обеспечение)
