## Как заполнять

1. Выгрузка из `AlgorithmNew01`:
   ```sql
   SELECT lessor, COUNT(DISTINCT wagon_id) AS wagons, AVG(rate) AS avg_rate,
          MIN(start_date), MAX(end_date)
   FROM RentDeal
   WHERE status = 'active'
   GROUP BY lessor
   ORDER BY wagons DESC;
   ```
2. Cверка от Павла (какие лизинги, какие частники, какие крупные)
