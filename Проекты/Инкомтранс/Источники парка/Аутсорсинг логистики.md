# Аутсорсинг логистики (Северный Путь)

Новое направление, где **СП сам выступает грузоотправителем** для клиента: привлекает вагоны у ИТ + сторонних операторов, продаёт комплексный сервис.

## Контекст запуска

- Направление уже имеет **2 действующих клиента** (грузоотправителем выступает СП)
- Проекты реализованы **до Фурсова** — специалисты ушли, направление «в подвешенном состоянии»
- **Костя Фурсов** — операционный руководитель (не продажник)

## Модель

```
КЛИЕНТ (грузовладелец)
        │
        │ комплексный сервис (сделка)
        ▼
СЕВЕРНЫЙ ПУТЬ (в роли грузоотправителя)
        │
        ├─── привлекает вагоны у ИТ
        │
        └─── привлекает вагоны у сторонних операторов
```

**Что покупает клиент:** не «вагон», а «доставку от ворот до ворот». Все хлопоты (планирование, документы, движение, простои) — на СП.

## Роль в общей стратегии

Это направление А из обсуждения 30.03.2026 — **«уход вверх»** к сервисной модели для грузовладельца. Стратегический ответ на риск от Цифрового Оператора (ЦО), где обезличенное распределение уменьшает ценность обычного оператора.
