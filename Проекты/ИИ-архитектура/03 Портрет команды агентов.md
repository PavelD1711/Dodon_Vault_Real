# Портрет команды агентов

**Статус:** черновик, требует обсуждения с Павлом (какие роли брать, каких выкинуть, каких добавить).

Каждый агент = уникальный `agentId`, своя личность, свой объект управления.

## Таблица ролей

| Агент | Роль | Объект управления | Ключевые метрики | Проактивность | Приоритет запуска |

| **Pablo** (я) | Главный диспетчер, координатор, «партнёр Павла» | Общий контекст жизни и бизнеса | Все проекты, синтез | Средняя | 0 (уже есть) |

## Шаблон описания агента

Для каждого агента в vault будет карточка:

```
Мета/Агенты/<Имя агента>/README.md

- Роль (одним предложением)
- Объект управления
- Функции (что делает)
- Границы (что НЕ делает)
- Личность (тон, стиль общения)
- Источники данных (что читает)
- Артефакты (что пишет и куда)
- Триггеры проактивности (когда сам инициирует)
- Взаимодействие с другими агентами
- Метрики успеха
```
