# 📋 Реестр проектов

> Обновляется автоматически через Dataview. Все проекты из папки `Проекты/` с полем `type: project` или `project_id`.

## Все активные проекты

```dataview
TABLE
  project_id as "#",
  title as "Название",
  roadmap as "ДК",
  type as "Тип",
  status as "Статус",
  life_area as "Контекст",
  owner as "Владелец",
  admin as "Админ",
  start as "Старт",
  deadline as "Дедлайн",
  closed_at as "Закрыт",
  goal as "Цель",
  kr as "KR",
  close_criteria as "Критерий"
FROM "Проекты"
WHERE file.name != "_Реестр проектов"
SORT status ASC, project_id ASC
```
