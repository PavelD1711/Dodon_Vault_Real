# 📋 Реестр проектов

> Обновляется автоматически через Dataview. Все проекты из папки `Проекты/` с полем `type: project` или `project_id`.

## Все активные проекты

```dataview
TABLE
  project_id as "#",
  title as "Название",
  roadmap as "ДК",
  type as "Тип",
  life_area as "Контекст",
  owner as "Владелец",
  admin as "Админ",
  deadline as "Дедлайн",
  status as "Статус"
FROM "Проекты"
WHERE file.name != "_Реестр проектов"
SORT status ASC, project_id ASC
```
