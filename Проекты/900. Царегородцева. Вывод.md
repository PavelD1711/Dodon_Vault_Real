## Разбор (closed_fail)

**Что планировалось:** нанять менеджера по вагонам.
**Что случилось:** сотрудник не прошёл испытательный срок, решение затянули на несколько месяцев.
**Корневая причина:** нет чёткого критерия/срока для принятия решения об увольнении на испытательном сроке.
**Риск:** затягивание решений по людям = лишние расходы на ФОТ + упущенное время на поиск нового.
**Следующий шаг:** зафиксировать риск в реестре рисков. Возможно — проект по формализации HR-процесса на испытательном сроке.
