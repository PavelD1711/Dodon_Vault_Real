# Контекст (24.08.2026)

Павел: «оба держат компанию через незаменимость функции»

- **Цимерман:** расчёт ставок, знание Алгоритма — «неубиваемая должность», может не брать доп. нагрузку и манипулировать этим
- **Ольга:** закупка вагонов / отношения с арендодателями — «оседлала функцию», остальное считает навязанным

**Корневая причина:** нет системы управления продажами — нет оцифрованной цели, нет пайплайна/воронки, нет регулярных отчётов, нет планирования командировок.

**Страх Павла:** расширить штат (нанять директора по продажам), а рыночной ёмкости для роста может не хватить.
