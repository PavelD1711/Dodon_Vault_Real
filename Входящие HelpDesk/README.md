# Входящие HelpDesk

Папка для фиксации всех входящих сущностей системы личного управления.

## Как использовать

1. Создать новую заметку через шаблон (`Шаблоны/Входящие — *`)
2. Заполнить свойства и суть
3. Сохранить со статусом `не_обработана`
4. Открыть дашборд → обработать → вписать `результат` и сменить статус

## Типы сущностей

| Тип | Шаблон | Результат |
|-----|--------|-----------|
| 💡 Идея | Входящие — Идея | → Проект или КР |
| 🔴 Проблема | Входящие — Проблема | → Задача / КР / Проект |
| 😨 Страх | Входящие — Страх | → Цель |
| 🔬 Гипотеза | Входящие — Гипотеза | → Проект / решение |
| ℹ️ Информация | Входящие — Информация | → Решение / архив |

## Правило обработки

Сущность считается обработанной когда:
- Статус изменён на `обработана` / `решена` / `проработан`
- Поле `результат` (или `цель`) заполнено ссылкой
