# Протоколы

## Протокол ДНЯ

### Утро (10–15 мин)
- Дыхание
- 1 приоритет дня
- Время для приоритета (когда именно)
- Защита от побега
- Прогноз триггеров (эйфория / тревога)

### День
- Однозадачность
- Перерывы 5 мин без экрана каждые 45–60 мин
- Защита утреннего блока (первый час без экранов)

### Вечер (10–15 мин)
- Галочка по приоритету (выполнен?)
- YAML-оценка состояния
- Вывод дня
- Триггеры итог
- Завтрашний приоритет

## Протокол СНА

| Время до сна | Действие |
|---|---|
| −60 мин | Без экранов |
| −45 мин | Дневник сна |
| −20 мин | Проветрить, умыться, приглушить свет |
| В постели | 5 вдохов + фраза завершения |
| Чтение | Бумажная книга 20–30 мин (спокойная, знакомая) |

## Протокол МЕЖСПРИНТА (6–10 дней)

### Шаг 1 — Рефлексия завершённого спринта
Письменно, 7 вопросов:
1. Что сделал?
2. Что не сделал и почему?
3. Какое состояние преобладало?
4. Какие паттерны повторились?
5. Какие корректирующие действия внёс?
6. Какие новые риски/проблемы заметил?
7. Какие триггеры эйфории/тревоги были сильнее всего?

### Шаг 2 — Анализ сущностей
Проверка и обновление реестров:
- Фейлы
- Риски
- Цели
- Проекты
- Корректирующие действия

### Шаг 3 — Планирование следующего спринта
- Фокус: 1–3 контекста
- Ключевые результаты: до 3
- Запреты
- Ежедневный ритуал
- Создание плана

### Шаг 4 — Переход
- Настройка среды (папка спринта, шаблоны)
- Ментальная настройка
- Первый день — лёгкий
