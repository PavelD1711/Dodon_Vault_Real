# Helpdesk — Логика и сущности

## Основная цепочка

**Страх → Цель → Риск → Проект → Задачи**

Каждый страх порождает цель. Каждая цель несёт риски. Каждый риск требует проекта. Каждый проект декомпозируется в задачи.

## Дополнительные сущности

- **Информация** — факты, данные, которые влияют на решения
- **Идея** — гипотеза о возможности, ещё не ставшая проектом
- **Проблема** — текущее препятствие
- **Гипотеза** — предположение, требующее проверки
- **Решение** — зафиксированный выбор из альтернатив

## Цикл обратной связи

**Проблема → Решение → Анализ → Риск → Корректирующее действие**

## Типология рисков

| Тип | Направление | Описание |
|-----|-------------|----------|
| **Ретроспективный** | Из прошлого | Паттерн, который уже случался и может повториться |
| **Проспективный** | Из будущего | Угроза, которая ещё не случилась, но вероятна |

## Карта связей (05)

Центральный документ Helpdesk — карта:
```
Страх ──→ Цель
           │
           ↓
          Риск ──→ Корректирующее действие
           │
           ↓
         Проект ──→ Задачи
```
