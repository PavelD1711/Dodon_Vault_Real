
# Дамп системы личного управления

## Контекст
Строю систему: стратегия + спринты + Helpdesk + Obsidian. Была инерция 2023–2025 (подавленность, побеги, кальян, алкоголь, прокрастинация). Первый спринт 2026 — лёгкий, восстановительный. Отвечай в Markdown для Obsidian.

## Параметры
- Год = 6 спринтов × 7 недель + межспринты 1–2 недели (~10 недель).
- Внутри спринта: недельная рефлексия + план. Запрещены изменение целей и рефлексия.
- План спринта не меняется после старта (кроме форс-мажора с записью в журнал решений).

## Helpdesk
Логика: Страх → Цель → Риск → Проект → Задачи.
Доп. сущности: Информация, Идея, Проблема, Гипотеза, Решение.
Цикл: Проблема → Решение → Анализ → Риск → Корректирующее действие.
Типы рисков: ретроспективный (из прошлого) и проспективный (из будущего).

## Протоколы
День: Утро (дыхание, 1 приоритет, время, защита от побега, прогноз триггеров) → День (однозадачность, перерывы 5 мин без экрана) → Вечер (галочка, YAML, вывод, триггеры, завтрашний приоритет).
Сон: за 60 мин — без экранов; за 45 — дневник; за 20 — проветрить/умыться; в постели — 5 вдохов + фраза. Чтение: бумажная книга 20–30 мин.
Межспринт (4 шага, 6–10 дней): Рефлексия → Анализ сущностей → Планирование → Переход.
