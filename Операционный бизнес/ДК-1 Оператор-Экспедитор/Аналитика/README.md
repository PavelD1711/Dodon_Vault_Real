# 📊 Аналитика — ДК-1 Оператор-Экспедитор

## Архитектура данных

Два источника питают стратегические решения по ДК:

### 1. Финансовая модель
Проекции, сценарии, юнит-экономика.
Файл: `Финансовая модель ОБ.md` (создать)
Источник: разрабатываем совместно

### 2. Отчётность (факт)
Регулярные данные — P&L, операционные показатели, дебиторка.
Папка: `Отчёты/`
Источники: 1С, БД Алгоритма, Битрикс24

## Связка
Отчётность → факт → сравниваем с финмоделью → корректируем ДК

## Промежуточные цели по функциям
При постановке KR нужно привязывать к функциям:
- Операционная (парк, оборот, простои)
- Финансовая (выручка, маржа, расходы)
- Коммерческая (продажи, клиенты, воронка)
- Команда (найм, делегирование, орг-структура)
