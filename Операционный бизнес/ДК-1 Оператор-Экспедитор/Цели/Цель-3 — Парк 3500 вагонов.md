# 🎯 Цель-3 — Парк 3500 вагонов в управлении

## Формулировка

Довести парк крытых вагонов в оперативном управлении до **3500 единиц** с чистой прибылью **≥50 млн руб/мес**.

**Это максимальная цель — вытекает из стратегического видения.**

> Цель-2 (≥5 млн/мес) — это стартовый норматив. Цель-3 (≥50 млн/мес + 3500 вагонов) — это финиш горизонта ДК.

## Контекст

- Текущий парк: **430 вагонов** (сентябрь 2026)
- Целевой парк: **3500 вагонов** (~8× рост)
- Горизонт: _уточнить_
- Путь роста: модель УК (передача чужих вагонов в оперативное управление) + собственная аренда

## Связь с другими целями

- **Цель-2 (≥5 млн руб/мес)** — минимальный норматив при текущем парке
- При 3500 вагонах потенциальная прибыль кратно выше → Цель-2 становится порогом начала пути, не финишем
- **Проект-1** (анализ рынка УК) — первый шаг к этой цели
