## 📄 Документы

*Общие:*
- [ ] Прайс-лист (Price list)
- [ ] Каталог / брошюра продукции
- [ ] Технический паспорт / спецификация на товар
- [ ] Упаковочный лист (Packing list) с размерами и весом
- [ ] Реквизиты компании
- [ ] Образец договора / условия сотрудничества
- [ ] Фото/видео производства

*Сертификаты (электроинструмент):*
- [ ] **CE** — обязательно для ЕС/Румынии
- [ ] **EMC test report** — электромагнитная совместимость
- [ ] **RoHS** — отсутствие вредных веществ
- [ ] **LVD** — директива по низкому напряжению
- [ ] **ISO 9001** — система менеджмента качества
- [ ] **CB Certificate** — международное взаимопризнание
- [ ] Декларация соответствия (DoC) — для таможни ЕС/Молдова

*Сертификаты (аккумуляторы / батареи):*
- [ ] **MSDS** — Material Safety Data Sheet (паспорт безопасности, таможня + транспортировка)
- [ ] **UN38.3** — тест литиевых батарей для авиа/морской перевозки
- [ ] **IEC 62133** — безопасность аккумуляторных батарей
- [ ] **CE**
- [ ] **RoHS**
- [ ] **IP рейтинг** (если корпусные блоки)
- [ ] **Декларация соответствия (DoC)**

*Сертификаты (электроскутер / e-mobility):*
- [ ] **WVTA** — Whole Vehicle Type Approval (одобрение типа, основа для CoC)
- [ ] **CoC** — Certificate of Conformity (для каждой единицы ТС)
- [ ] **CE**
- [ ] **EMC test report**
- [ ] **UN38.3** — сертификат батареи (литий) для перевозки
- [ ] **RoHS**
- [ ] **IP рейтинг** — степень защиты (IP54/IP67)
- [ ] **Декларация соответствия (DoC)**
- [ ] **Type Approval** — для регистрации в ГАИ Молдовы/Румынии
