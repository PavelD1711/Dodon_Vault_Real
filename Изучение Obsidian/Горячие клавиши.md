
**Ctrl+P / Cmd+P** — открыть палитру команд  
**Ctrl+, / Cmd+,** — открыть настройки  
**Ctrl+N / Cmd+N** — создать новую заметку  
**Ctrl+T / Cmd+T** — создать новую вкладку  
**Ctrl+Shift+F / Cmd+Shift+F** — поиск по всем заметкам  
**Ctrl+F / Cmd+F** — поиск по заметке  
**Ctrl+O / Cmd+O** — быстрый переход  
**Ctrl+E / Cmd+E** — переключить режим редактирования/просмотра  
**Ctrl+B / Cmd+B** — жирный текст
Alt (option) + B - добавление заметки в закладки.
