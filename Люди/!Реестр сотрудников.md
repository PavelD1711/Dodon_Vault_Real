# Реестр сотрудников

```dataview
TABLE WITHOUT ID
  link(file.path, имя) AS "Сотрудник",
  роль AS "Роль",
  dateformat(date(дата_выхода), "dd.MM.yyyy") AS "Дата выхода",
  dateformat(date(дата_увольнения), "dd.MM.yyyy") AS "Дата увольнения",
  статус AS "Статус",
  подчинение AS "Подчинение"
FROM "Люди"
WHERE имя != null AND !contains(file.path, "_ШАБЛОН")
SORT статус ASC, дата_выхода DESC
```
