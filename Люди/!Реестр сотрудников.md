# Реестр сотрудников

```dataview
TABLE WITHOUT ID
  link(file.path, имя) AS "Сотрудник",
  роль AS "Роль",
  дата_выхода AS "Дата выхода",
  дата_увольнения AS "Дата увольнения",
  статус AS "Статус",
  подчинение AS "Подчинение"
FROM "Люди"
WHERE имя != null
SORT статус ASC, дата_выхода DESC
```

**Статусы:** `активен` · `испытательный` · `уволен` · `переведён`
