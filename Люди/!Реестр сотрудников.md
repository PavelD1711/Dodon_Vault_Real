# 👥 Реестр сотрудников

## Активные

```dataview
TABLE WITHOUT ID
  link(file.path, имя) AS "Сотрудник",
  роль AS "Роль",
  dateformat(date(дата_выхода), "dd.MM.yyyy") AS "Выход",
  подчинение AS "Руководитель"
FROM "Люди"
WHERE имя != null
  AND !contains(file.path, "_ШАБЛОН")
  AND (статус = "активен" OR статус = "испытательный")
SORT дата_выхода DESC
```

## 🔵 Испытательный срок

```dataview
TABLE WITHOUT ID
  link(file.path, имя) AS "Сотрудник",
  роль AS "Роль",
  dateformat(date(дата_выхода), "dd.MM.yyyy") AS "Выход",
  dateformat(date(дата_выхода) + dur(90 days), "dd.MM.yyyy") AS "Конец испытательного"
FROM "Люди"
WHERE имя != null
  AND !contains(file.path, "_ШАБЛОН")
  AND статус = "испытательный"
SORT дата_выхода DESC
```

## 🔴 Уволены

```dataview
TABLE WITHOUT ID
  link(file.path, имя) AS "Сотрудник",
  роль AS "Роль",
  dateformat(date(дата_выхода), "dd.MM.yyyy") AS "Выход",
  dateformat(date(дата_увольнения), "dd.MM.yyyy") AS "Уволен"
FROM "Люди"
WHERE имя != null
  AND !contains(file.path, "_ШАБЛОН")
  AND статус = "уволен"
SORT дата_увольнения DESC
```
