# 👥 Реестр сотрудников

## 🟢 Активные

```dataview
TABLE WITHOUT ID
  link(file.path, name) AS "Сотрудник",
  role AS "Роль",
  dateformat(date(start_date), "dd.MM.yyyy") AS "Дата выхода",
  manager AS "Руководитель"
FROM "Люди"
WHERE status = "active"
  AND file.folder = "Люди"
SORT file.name ASC
```

## 🔵 Испытательный срок

```dataview
TABLE WITHOUT ID
  link(file.path, name) AS "Сотрудник",
  role AS "Роль",
  dateformat(date(start_date), "dd.MM.yyyy") AS "Дата выхода",
  dateformat(date(start_date) + dur(90 days), "dd.MM.yyyy") AS "Конец испытательного"
FROM "Люди"
WHERE status = "probation"
  AND file.folder = "Люди"
SORT file.name ASC
```

## 🔴 Уволены

```dataview
TABLE WITHOUT ID
  link(file.path, name) AS "Сотрудник",
  role AS "Роль",
  dateformat(date(start_date), "dd.MM.yyyy") AS "Дата выхода",
  dateformat(date(end_date), "dd.MM.yyyy") AS "Дата увольнения"
FROM "Люди"
WHERE status = "fired"
  AND file.folder = "Люди"
SORT file.name ASC
```
