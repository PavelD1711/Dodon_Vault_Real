# Vault Workshop

**Мета-раздел про сам vault** — не про содержимое (проекты, финмодель, люди), а про **как мы его ведём**.

## Что здесь живёт

- Правила структуры папок
- Соглашения по именованию файлов
- Стандарты frontmatter для сущностей
- Каталог плагинов и как их настраивать
- Dataview-запросы и дашборды
- Правила синхронизации (obsidian-git, конфликты)
- Wikilinks-политика, тэги
- Шаблоны (Templater)

## Что тут НЕ живёт

- **Методология проектного управления** → `Методология/` (сущности: проект, KR, событие, риск, гейт)
- **Содержательные проекты** → `Проекты/`
- **Люди** → `Люди/`

Разница: `Методология/` — про **что** такое проект (KR, события, риски). `Мета/Vault Workshop/` — про **как** это устроено в файлах (frontmatter, папки, плагины).
