# Цель и постановка

## Формулировка цели (со слов Павла, 20.09.2026)

Создать **команду специализированных AI-агентов**, где каждый:

1. **Эксперт в своей области** — не «универсал», а узкий специалист
2. **Сфокусирован на конкретной функции** (анализ / контроль / планирование / коммуникация / …)
3. **Имеет конкретный объект управления** (время / деньги / парк вагонов / SKU / …)
4. **Умеет взаимодействовать с другими агентами** — не изолирован

## Принципы (мои гипотезы, требуют утверждения)

1. **Один агент = одна роль** — не смешивать «финансист + юрист + переговорщик»
2. **Общее состояние через файлы** — vault, memory, journal — все агенты пишут и читают там
3. **Владелец файла = один агент** — чтобы избежать конфликтов записи
4. **Оркестратор** (Pablo в основной DM) — принимает задачу, решает кому делегировать
5. **Прямой доступ Павла** — Павел может обратиться к любому агенту напрямую, минуя оркестратора
6. **Регламент проактивности** — какие агенты сами инициируют (Time Assistant), какие только реактивные

## Метрики успеха

_(черновые, требуют доработки)_

- **Скорость реакции** на специализированный вопрос (в контексте узкой области)
- **Качество ответа** — эксперт в области отвечает лучше универсала
- **Отсутствие «текстового дрейфа»** — агент не путает роли
- **Разделение когнитивной нагрузки** — Павел не должен держать в голове «кому что делегировано»
- **Стоимость** (LLM-токены) — прирост не превышает 2-3× относительно моно-агента

## Что НЕ является целью

- Заменить всю команду людей — агенты дополняют, не заменяют
- Автономная работа без Павла — Павел остаётся центром принятия решений
- Идеальная оркестрация с первого раза — итеративное разворачивание
