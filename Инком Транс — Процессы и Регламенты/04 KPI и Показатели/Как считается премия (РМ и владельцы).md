# Как считается премия
**Для региональных менеджеров и владельцев договоров · Q1–Q2 2026**

---

## Часть 1. Премия владельца договора

Владелец получает премию за то, что клиент есть и возит. Расчёт по каждому рейсу отдельно.

### Шаг 1. Фонд квартала
```
ФОНД = приведённая выручка квартала × ставка (0,5%)
```
Ставка задаётся на листе «Параметры».

### Шаг 2. Приведённая выручка рейса
Выручка каждого рейса умножается на коэффициент дороги — чтобы выровнять разницу в уровне ставок.
```
приведённая выручка = выручка рейса × коэффициент дороги
```

| Дороги | Коэффициент |
|--------|-------------|
| МСК, ОКТ, КБШ, ГОР | 0,5 |
| ЗСБ, СКВ, ЮВС, СВР | 1,0 |
| КЗХ, ЮУР | 1,5 |
| АЗР, ДВС | 2,0 |
| ЗАБ | 3,5 |
| ТРК | 5,0 |

Средний по сети = 1. Коэффициенты кратны 0,5.

### Шаг 3. Премия рейса
```
премия рейса = приведённая выручка × ставка
```
Цена приведённого рубля одинакова для всех дорог.

**Пример:** два рейса дают одинаковую премию:
| Рейс | Выручка | Коэф. | Приведённая | Премия |
|------|---------|-------|-------------|--------|
| ЗАБ | 50 000 | 3,5 | 175 000 | 875 ₽ |
| МСК | 350 000 | 0,5 | 175 000 | 875 ₽ |

### Шаг 4. Привлечённый парк
```
премия = (выручка − затраты) × 5%
```
Ставка 5%. Отрицательная маржа премии не даёт.

### Шаг 5. Итог
```
премия владельца = премия по аренде + премия по привлечённому парку
```

## Часть 2. Премия регионального менеджера

РМ отвечает за качество работы парка на своих дорогах — не за наличие клиента.

### Шаг 1. База премии
Приведённая выручка дорог менеджера × ставка. Это максимум, который РМ может получить.

### Шаг 2. Три показателя и их веса

| Показатель | Вес | Что хорошо |
|------------|-----|------------|
| Средний чек гружёного рейса | 40% | выше |
| Чек порожнего на гружёный | 30% | ниже |
| ПРР на гружёный рейс | 30% | ниже |

### Шаг 3. Порог (ТБУ) по каждому показателю
- факт **хуже** ТБУ → доля премии **не платится**
- факт **лучше** ТБУ → доля **выплачивается полностью**

Пороги независимы: можно провалить один показатель и получить остальные.

> ⚠️ **Про порожний:** цель считается не средней ставкой по дорогам, а суммой целевых расходов ÷ гружёные рейсы. Так в расчёт попадают перегонные дороги (УЗБ, КРГ, ТДЖ) — где вагоны идут порожняком без обратной загрузки.

### Шаг 4. Эффект в рублях
```
эффект по чеку      = (факт − цель) × рейсы
эффект по порожнему = (цель − факт) × рейсы
эффект по ПРР       = (цель − факт) × рейсы × суточная маржа (515 ₽)
```
По ПРР: каждые сэкономленные сутки простоя — это вагоно-сутки с обычной доходностью.

### Шаг 5. Надбавка от привлечённого парка
```
остаток = маржа привлечённого + эффект   (если эффект < 0)
остаток = маржа привлечённого            (если эффект ≥ 0)

остаток > 0  →  надбавка = остаток × 5%
остаток ≤ 0  →  надбавки нет
```

### Шаг 6. Итог
```
премия РМ = премия по показателям + надбавка
```

## Сравнение: владелец vs РМ

| | Владелец | РМ |
|--|----------|----|
| За что | за клиента и объём | за качество работы парка |
| База | приведённая выручка | приведённая выручка своих дорог |
| Пороги | нет | три независимых |
| Привлечённый парк | 5% от маржи напрямую | покрывает минус, потом 5% с остатка |
