# Мой центр управления

Главная папка стратегического ассистента. Здесь хранится всё, что определяет кто я, куда иду и как управляю временем.

## Структура

```
Мой центр управления/
├── Идеология/
│   ├── Личная конституция.md      ← ценности, принципы, правила жизни
│   ├── Годовые обязательства.md   ← что обещал себе на этот год
│   └── Анти-цели.md               ← от чего сознательно отказываюсь
├── Время/
│   ├── Контексты жизни.md ✅       ← 11 контекстов (разобрано 21.09.2026)
│   ├── Доктрина времени.md        ← годовой бюджет по контекстам
│   └── Регулярные мероприятия.md  ← форум-группа и другие фиксированные события
├── Планирование/
│   ├── Система спринтов.md ✅      ← ритмика год/спринт/неделя/день
│   ├── Цели года.md               ← 1 главный результат + цели по контекстам
│   ├── Спринт текущий.md          ← живой документ текущего спринта
│   └── Архив спринтов/            ← итоги прошлых спринтов
├── Стратегия/
│   ├── Стоимость решений.md       ← журнал разборов «брать / не брать»
│   └── Долгосрочное видение.md    ← куда иду на горизонте 3-5 лет
└── Бизнес/
    ├── Роли в бизнесе.md          ← в каких ролях участвую в ОБ
    └── Портфель активов.md        ← что входит в Family Office
```

## Правила редактирования

1. Все документы живут только здесь — `Мой центр управления/`
2. Редактируем вместе с Pablo — он предлагает черновик, Павел принимает
3. Существенные изменения → Pablo дублирует в `memory/` (для поиска)
4. Раз в квартал (в меж-спринте) — ревизия всех документов

## Инструменты

- **Toggl Track** — факт по контекстам
- **Google Sheets** — [Time Budget](https://docs.google.com/spreadsheets/d/1l-ZfP3vDcgCddnGTWQHrW6cTwDZgTS7NbSA-p9CT680/edit)
- **Google Calendar** — блокировка времени + регулярные мероприятия
- **Yougile** — спринты и задачи
