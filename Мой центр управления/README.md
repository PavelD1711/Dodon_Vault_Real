# Мой центр управления

Главная папка стратегической системы управления жизнью. Здесь хранится всё, что определяет кто я, куда иду и как управляю временем.

---

## 🤖 Time Assistant — кто это и что делает

**Time Assistant (Pablo)** — стратегический ассистент, работающий в Telegram-группе «Time Assistant» (`-5521808848`).

### Роль

Диспетчер времени + стратегический советник. Объединяет две функции:
1. **Бюджет времени** — считает, раскладывает, контролирует факт vs норматив
2. **Идеологический контур** — знает ценности, принципы, правила Павла и опирается на них при рекомендациях

### 5 функций

| # | Функция | Описание |
|---|---------|----------|
| 1 | 🧮 Считает | Сколько реально есть часов — за вычетом сна, быта, буфера |
| 2 | 📊 Раскладывает | По 11 контекстам жизни: норматив в часах и % |
| 3 | 🎯 Управляет фокусом | Держит модель «куда идёшь, что съедает время» |
| 4 | 🔍 Анализирует | Факт из Toggl vs норматив — отклонения, тренды |
| 5 | ✋ Говорит правду | «На это времени нет. Варианты: делегировать X, урезать Y, отложить Z» |

### Как работает с контекст-агентами

Time Assistant — диспетчер. Когда видит перекос в бюджете:
- Ставит цель контекст-агенту: «Сократить личное время в ОБ с 50 до 25 ч/нед»
- Контекст-агент анализирует и ищет возможности внутри своего контекста
- Отчитывается фактом → Time Assistant корректирует бюджет

```
Time Assistant → бюджетная цель → Контекст-агент
Контекст-агент → факт → Time Assistant
Time Assistant → корректировка → Контекст-агент
```

## Правила редактирования

1. Все документы живут только здесь — `Мой центр управления/`
2. Редактируем вместе с Pablo — он предлагает черновик, Павел принимает
3. Существенные изменения → Pablo дублирует в `memory/` (для поиска)
4. Раз в квартал (в меж-спринте) — ревизия всех документов
