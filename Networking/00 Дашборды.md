# Networking — дашборды

Все запросы работают через плагин **Dataview**. Обновляются автоматически.

## 🔥 Кому пора написать

Люди, у которых `дата_последнего_контакта` старше периодичности контакта.

```dataview
TABLE
  роли AS "Роли",
  компания AS "Компания",
  дата_последнего_контакта AS "Последний контакт",
  периодичность AS "Периодичность",
  следующий_контакт AS "След. контакт"
FROM "Networking"
WHERE тип = "человек" AND следующий_контакт != null AND date(следующий_контакт) <= date(today)
SORT date(следующий_контакт) ASC
```

## 📅 Ближайшие плановые контакты (30 дней)

```dataview
TABLE
  роли AS "Роли",
  компания AS "Компания",
  следующий_контакт AS "Когда"
FROM "Networking"
WHERE тип = "человек" AND следующий_контакт != null 
  AND date(следующий_контакт) > date(today)
  AND date(следующий_контакт) <= date(today) + dur(30 days)
SORT date(следующий_контакт) ASC
```

## 🎂 Дни рождения (ближайшие 60 дней)

_Требует dataviewjs для сравнения по «месяц-день», без учёта года. Пока используем простое отображение всех:_

```dataview
TABLE день_рождения AS "ДР", компания AS "Компания"
FROM "Networking"
WHERE тип = "человек" AND день_рождения != null
SORT день_рождения ASC
```

## 📊 Общая статистика

```dataviewjs
const people = dv.pages('"Networking"').where(p => p.тип === "человек")
const total = people.length
const byStatus = {}
const byRole = {}

for (const p of people) {
  byStatus[p.статус || 'не_указано'] = (byStatus[p.статус] || 0) + 1
  const roles = Array.isArray(p.роли) ? p.роли : [p.роли]
  for (const r of roles.filter(Boolean)) {
    byRole[r] = (byRole[r] || 0) + 1
  }
}

dv.paragraph(`**Всего людей в базе:** ${total}`)
dv.header(4, "По статусу")
dv.table(["Статус", "Кол-во"], Object.entries(byStatus).sort((a,b)=>b[1]-a[1]))
dv.header(4, "По ролям")
dv.table(["Роль", "Кол-во"], Object.entries(byRole).sort((a,b)=>b[1]-a[1]))
```
