# Networking — дашборды

Все запросы работают через плагин **Dataview**. Обновляются автоматически.

## 🔥 Кому пора написать

```dataview
TABLE
  роли AS "Роли",
  компания AS "Компания",
  дата_последнего_контакта AS "Последний контакт",
  периодичность AS "Периодичность",
  следующий_контакт AS "След. контакт"
FROM "Networking"
WHERE тип = "человек" AND следующий_контакт != null AND date(следующий_контакт) <= date(today)
SORT date(следующий_контакт) ASC
```

## 📅 Ближайшие плановые контакты (30 дней)

```dataview
TABLE
  роли AS "Роли",
```

# 🕸️ Граф связей

## 🌉 Мои мосты (кто через кого меня знает)

_Люди, через которых я знаю других (`знаком_через` заполнено)._

```dataview
TABLE знаком_через AS "Мосты (через кого знаю)", компания AS "Компания", статус AS "Статус"
FROM "Networking"
WHERE тип = "человек" AND знаком_через != null AND length(знаком_через) > 0
SORT file.name ASC
```

## 🎭 Мои super-connectors (кто знает многих)

_Люди, у которых заполнено `знает_людей` — потенциально могут дать интро._

```dataview
TABLE знает_людей AS "Знает из моих контактов", length(знает_людей) AS "Кол-во"
FROM "Networking"
WHERE тип = "человек" AND знает_людей != null AND length(знает_людей) > 0
SORT length(знает_людей) DESC
```

## 🔗 Обратная сеть: кто ведёт к кому (через кого можно выйти)

_Для каждого человека — все, у кого он числится в `знает_людей` (то есть кто может нас с ним познакомить)._

```dataview
TABLE without id target AS "К кому", rows.file.link AS "Через кого"
FROM "Networking"
WHERE тип = "человек" AND знает_людей != null
FLATTEN знает_людей AS target
GROUP BY target
SORT length(rows) DESC
```

## 🎯 2nd-degree сеть (знаком через кого-то, лично нет)

```dataview
TABLE знаком_через AS "Через", компания AS "Компания", роли AS "Роли", экспертиза AS "Экспертиза"
```

## 🏝️ Изолированные узлы (тупики)

_Люди без связей — никого не знают в моей базе, никто не знает про них._

```dataviewjs
const people = dv.pages('"Networking"').where(p => p.тип === "человек")
const isolated = []
for (const p of people) {
  const knowsSomeone = Array.isArray(p.знает_людей) && p.знает_людей.filter(x => x && x.path).length > 0
  const knownVia = Array.isArray(p.знаком_через) && p.знаком_через.filter(x => x && x.path).length > 0
  
  // Проверяем, есть ли обратные ссылки — упомянут ли он в чьих-то знает_людей
  let referenced = false
  for (const other of people) {
    if (other.file.path === p.file.path) continue
    if (Array.isArray(other.знает_людей)) {
      for (const link of other.знает_людей) {
        if (link && link.path === p.file.path) { referenced = true; break }
      }
    }
    if (referenced) break
  }
  
  if (!knowsSomeone && !knownVia && !referenced) {
    isolated.push([p.file.link, p.компания, p.статус])
  }
}

if (isolated.length === 0) {
  dv.paragraph("✅ Изолированных узлов нет — все люди в графе связаны.")
} else {
  dv.paragraph(`Изолированных узлов: ${isolated.length}`)
  dv.table(["Файл", "Компания", "Статус"], isolated)
}
```

# 📊 Общая статистика

```dataviewjs
const people = dv.pages('"Networking"').where(p => p.тип === "человек")
const total = people.length
const byStatus = {}
const byRole = {}
let withKnowsPeople = 0
let withKnownVia = 0

for (const p of people) {
  byStatus[p.статус || 'не_указано'] = (byStatus[p.статус] || 0) + 1
  const roles = Array.isArray(p.роли) ? p.роли : [p.роли]
  for (const r of roles.filter(Boolean)) {
    byRole[r] = (byRole[r] || 0) + 1
  }
  if (Array.isArray(p.знает_людей) && p.знает_людей.filter(x => x && x.path).length > 0) withKnowsPeople++
  if (Array.isArray(p.знаком_через) && p.знаком_через.filter(x => x && x.path).length > 0) withKnownVia++
}

dv.paragraph(`**Всего людей в базе:** ${total}`)
dv.paragraph(`**Заполнили «знает людей»:** ${withKnowsPeople} (${Math.round(withKnowsPeople/total*100 || 0)}%)`)
dv.paragraph(`**Заполнили «знаком через»:** ${withKnownVia} (${Math.round(withKnownVia/total*100 || 0)}%)`)

dv.header(4, "По статусу")
dv.table(["Статус", "Кол-во"], Object.entries(byStatus).sort((a,b)=>b[1]-a[1]))
dv.header(4, "По ролям")
dv.table(["Роль", "Кол-во"], Object.entries(byRole).sort((a,b)=>b[1]-a[1]))
```
