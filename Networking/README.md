# Networking — база личных контактов и граф связей

Плоская папка со всеми людьми (бизнес + проф. знакомые). Классификация — через frontmatter (`роли`, `статус`, `экспертиза`, `периодичность`), дашборды — через dataview, **поиск маршрутов через агента (меня)**.

## 🎯 Ключевая идея — граф связей

База — это не список, а **граф**:
- **Узел** = человек (файл в `Networking/`)
- **Рёбра** = поля frontmatter (`знаком_через`, `знает_людей`, `связанные_люди`)

Это даёт две мощные фичи:

1. **2nd-degree сеть** — люди, которых ты знаешь через кого-то (статус = `не_знаком_лично`, поле `знаком_через` заполнено)
2. **Поиск маршрутов** — «есть ли у нас выход на такого-то?» → я нахожу путь через граф

## Как заносить нового человека

1. Открыть `Шаблоны/Человек.md`, скопировать в `Networking/`
2. Назвать файл: **`Имя Фамилия.md`** (например `Отабек Умаров.md`)
3. Заполнить frontmatter (обязательные поля: `имя`, `компания`, `роли`, `статус`, `дата_знакомства`)
4. Написать «О человеке» и «Как познакомились» — минимум
5. **Заполнить связи** (ключевое для графа!):
   - Если знаешь через кого-то → `знаком_через: [[Иванов]]`
   - Если знаешь, кого он знает из твоей базы → `знает_людей: [[Петров]]`
6. Остальное — по мере появления информации

## Как задавать вопросы для поиска маршрутов

Просто пиши мне в чат нативным языком:

**Примеры:**
- «Есть ли у нас выход на Иванова из ТрансРоссии?»
- «Через кого я могу выйти на CFO Ромашки?»
- «Кто в моей сети может представить меня фонду X?»
- «Найди все маршруты от меня до Сидорова длиной не больше 3 шагов»
- «Кто мои supet-connectors (знает больше всего людей)?»

Что я делаю:
1. Читаю всю папку `Networking/`
2. Строю граф в памяти
3. Ищу пути через BFS (обход в ширину)
4. Выдаю список маршрутов, отсортированных по:
   - Длине пути (короче = лучше)
   - Качеству связей (`качество_связей: сильная/средняя/слабая`)
   - Твоему уровню доверия к промежуточному человеку

**Пример вывода:**
```
Найдено 3 маршрута до [[Сергей Козлов (Металлтрейд)]]:

Маршрут 1 (длина 2, сильные связи):
  Ты → [[Аня Сухова]] (доверие 5, активно) → Сергей Козлов
  Аня давно работает с Металлтрейдом, самый прямой путь.

Маршрут 2 (длина 2, средние связи):
  Ты → [[Фурсов]] (доверие 4) → Сергей Козлов
  Через логистику, косвенное знакомство.

Маршрут 3 (длина 3, длинный):
  Ты → [[Отабек Умаров]] → [[Петров Иван]] → Сергей Козлов
```

## Правила именования

- **Файл:** «Имя Фамилия.md» (кириллица ОК). Если удобнее по фамилии — «Фамилия Имя.md»
- **Дубликаты** (два человека с одним именем) — добавить компанию: `Иван Петров (Северный Путь).md`
- **Не переименовывай** после того как на файл появятся ссылки (или используй Obsidian rename для авто-обновления)

## Роли (справочно)

| Роль | Кто это |
|---|---|
| `партнёр` | С кем есть совместный бизнес/проекты |
| `клиент` | Покупает у меня услуги |
| `поставщик` | Я покупаю услуги/товары |
| `эксперт` | Консультирует, разбирается в теме |
| `инвестор` | Может дать/дал денег в проект |
| `сотрудник` | В команде (текущий) |
| `бывший_сотрудник` | Работал у меня |
| `юрист` | Юр.консультации |
| `банкир` | Работа с банком |
| `чиновник` | В госструктурах |
| `предприниматель` | Собственный бизнес, но пока не партнёр |
| `коллега` | Из моей ниши, взаимный обмен опытом |
| `ментор` | Учит меня |
| `знакомый` | Просто на связи |
| `друг` | Личное общение вне работы |

## Статусы отношений

| Статус | Смысл |
|---|---|
| `не_знаком_лично` | ⭐ Знаю про него через кого-то, но лично не встречался. Заполни `знаком_через`! |
| `не_контактируем` | Отношения были, сейчас не общаемся |
| `знакомы` | Знаем друг друга, редкие точки контакта |
| `активно` | Регулярно общаемся по делу |
| `близко` | Доверительные, глубокие отношения (пока не друзья) |
| `друзья` | Личное общение, дружба |

## Периодичность контакта

| Значение | Что значит |
|---|---|
| `еженедельно` | Раз в неделю |
| `ежемесячно` | Раз в месяц |
| `ежеквартально` | Раз в квартал |
| `раз_в_полгода` | Полугодовая точка |
| `ежегодно` | Раз в год (например, поздравление) |
| `по_случаю` | По ситуации, без графика |

## Качество связей (для приоритизации маршрутов)

В поле `качество_связей` можно помечать силу связи между текущим человеком и другими:

```yaml
качество_связей:
  "[[Иванов Иван]]": сильная    # партнёры/друзья, часто общаются
  "[[Петров Пётр]]": средняя    # знают друг друга, редкие контакты
  "[[Сидоров]]": слабая         # знакомы, давно не виделись
```

Значения:
- **`сильная`** — партнёры, друзья, регулярное общение, доверие
- **`средняя`** — знают друг друга, периодические контакты
- **`слабая`** — знакомы, давно не общались, «когда-то виделись»
