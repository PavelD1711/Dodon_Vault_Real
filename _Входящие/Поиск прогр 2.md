🚩 Риск №2 — Он работает соло, а проект на 6-9 месяцев

Проблема:

• Один разработчик = 6-9 месяцев реального времени
• Если он заболеет / уйдёт / решит "поднять цены" — весь бус-фактор на нём
• Кузнецов и Морозков будут его ждать, а команда простаивает

🚩 Риск №3 — ЕР не масштабируется на длинные проекты

Модель Антара идеальна для проектов 5-15 ЕР (350к-1млн). На длинных проектах:

• Скрытая инфляция ЕР — «сложнее чем думали», «требования уточнились»
• Нет overhead-эффекта — на длинных проектах архитектура и переиспользование должны снижать стоимость
• Нет скидки за объём — «партнёрская» 22% от «стандартной», это несерьёзно для 60-80 ЕР

✅ Мой честный ответ

Да, модель Антара для этого проекта слишком дорогая. По трём причинам:

1. AI-планировщик по его тарифу = 1,7-2,5 млн, а по рынку та же задача 900к-1,5 млн
2. Соло-модель не подходит для 6-9 месячных проектов — bus factor критичен
3. «Партнёрская» скидка 22% мала для объёма 60-80 ЕР

Правильная стратегия для CargoLogic:

Вариант A — Гибрид (рекомендую)

• Антар делает 15-25 ЕР по его сетке = 1-2 млн — критические интеграции (ЭТРАН, ГИС ЭПД), где нужна аккуратная работа
• Fixed-price подрядчик делает основной массив по проектной модели = 2-3 млн — процессы, экраны, отчёты
• Я (Pablo) делаю AI-планировщик как MVP → потом отдаём кому-то на прод = экономия 500к-1млн
• Итого: 3,5-5 млн вместо 5-7 млн

Вариант B — Разделить на этапы, тендерить каждый

• Разбить бэклог на 3-4 фазы по 3 месяца
• Каждую фазу — отдельный тендер между 2-3 подрядчиками (Антар vs альтернативы)
• Кто лучше по цене/скорости — тот получает эту фазу
• Итого: гибкая работа, риск раскладывается на этапы

Вариант C — Свой мини-CTO вместо ЕР

• Нанять сильного tech-lead в штат на 250-350к/мес × 6-9 мес = 1,5-3 млн ЗП
• Плюс 1-2 фрилансера на 200-300к/мес × 6-9 = 1,2-2,7 млн
• Итого 2,7-5,7 млн, но у тебя остаётся команда и права на код
