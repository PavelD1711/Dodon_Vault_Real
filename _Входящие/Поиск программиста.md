
Хороший ход — не привязываться к одному подрядчику. Разложу по площадкам, с плюсами-минусами каждой.

  

🎯 5 путей найти альтернативу Антару

1. 🌐 Habr Career — главный источник в РФ

  

URL: career.habr.com

  

Как искать:

  

• Раздел «Фриланс» или «Найти сотрудника»

• Фильтры: Python/Node.js/full-stack + опыт «Senior» или «Lead» + удалёнка

• Смотри пометку «AI/ML» — если делает AI-сценарии

  

Что даёт:

  

• Инженерное качество разработчиков высокое

• Многие с публикациями в блоге Хабра — можно почитать «как думает»

• Rate: 3-6к/ч для middle-senior

  

Минусы: топовые часто заняты в найме, не берут проекты.

Самый эффективный канал в РФ 2026. Смотри:

  

Каналы вакансий (постишь свою):

  

• @buhtysh — hh для айтишников (85к подписчиков)

• @remote_ru — удалённая работа

• @it_bez_zapreta — IT-вакансии

• @developers_ru_jobs

Профильные чаты по стекам:

  

• @ru_python, @python_flood

• @nodejs_ru

• @sql_ru

• @aihackers, @llm_under_hood — по AI/RAG

Как искать: пишешь пост «Ищу разработчика на проект X, оплата Y, задачи A/B/C». Откликаются десятки.

  

Плюсы: быстро, живо, много кандидатов

Минусы: качество разное, надо фильтровать

3. 🔧 GitHub — по коду, а не по резюме

  

Это моя любимая методика и лучший фильтр качества.

  

Как ищешь:

  

1. Заходишь на GitHub, ищешь пользователей по фильтрам: language:Python location:Russia followers:>50

2. Смотришь у кого есть свои проекты (не форки), пишут регулярно, есть звёзды

3. Смотришь код: читаемый ли? Есть ли тесты? Документация?

4. Пишешь в LinkedIn или через email профиля

  

Что искать конкретно для твоих задач:

  

• intgration amocrm python site:github.com

• telegram bot python production

• RAG langchain openai

• postgresql sqlalchemy fastapi

  

Плюсы: видишь реальный код, а не рассказы. Кто врёт про уровень — сразу видно.

Минусы: долго, нужно уметь читать код (я могу помочь с оценкой).

5. 🤝 Рекомендации от IT-предпринимателей

  

Самый недооценённый канал. Ты — предприниматель, у тебя точно есть 5-10 знакомых, которые заказывали разработку. Спроси у них:

  

• Кто делал → результат → цена → скорость → рекомендуешь?

• Кто был плохой? (чтобы избежать)

  

Хорошие места где спрашивать:

  

• Клубы предпринимателей (Клуб бизнес-хакеров, Атланты, Эквиум)

• LinkedIn — прямо пост «Ищу разработчика на проект X»

• Форумы вроде [VC.ru](http://vc.ru/) — раздел «Найти команду»

  

Плюсы: с готовой репутацией, без сюрпризов

Минусы: таких обычно уже нет свободных

🎯 Что бы я делал на твоём месте

  

Стратегия параллельного тендера:

  

Шаг 1 — за 1 день собрать 5-7 кандидатов:

  

• 2 с Habr Career (по репутации)

• 2 из Telegram-чатов (по стеку)

• 1-2 из GitHub (по коду)

• 1 через рекомендацию

  

Шаг 2 — дать всем одну и ту же простую задачу для оценки:

  

• Например: «Нужна интеграция Yougile → Google Sheets. При создании задачи в проекте X автоматически создаётся строка в таблице Y с полями A/B/C. Обновление задачи — обновление строки. Технические требования: Python или Node.js, деплой в наш VPS, поддержка после сдачи 30 дней.»

• Проси ответ в формате: часы + деньги + сроки + план работ

• Смотришь как думает каждый, а не только цену

Шаг 3 — сравнить с Антаром:

  

• Если он в рынке — ок, работайте

• Если сильно дороже — есть аргумент торговаться

• Если сильно дешевле — красный флаг у остальных (мутит с качеством?)

  

Шаг 4 — маленький тестовый проект тем, кто прошёл первый фильтр. Не рамочный договор сразу, а 1-2 ЕР.
