
# Подробная программа изучения ИИ: разбивка по блокам

Расчёт — на 10 часов в неделю. Если у вас меньше, растягивайте недели, но не меняйте порядок и пропорцию «треть теории / две трети практики».

---

## Этап 0. Ориентация — 15–25 часов (2 недели)

**Цель:** карта местности и общий словарь.

**Неделя 1 (~10 ч)**
- Курс Elements of AI, главы 1–3: что такое ИИ, поиск решений, вероятности в ИИ (~6 ч)
- Видео 3Blue1Brown «But what is a neural network?» + «Gradient descent» (~2 ч)
- Завести конспект: выписать своими словами 20 терминов (модель, датасет, обучение, токен, эмбеддинг, промпт, галлюцинация, контекст и т.д.) (~2 ч)

**Неделя 2 (~10 ч)**
- Elements of AI, главы 4–6: машинное обучение, нейросети, влияние на общество (~6 ч)
- Видео 3Blue1Brown про LLM и трансформеры (обзорно, без цели понять всё) (~2 ч)
- Практика: 2 часа осознанной работы с Claude/ChatGPT — попробовать разные формулировки одной задачи, заметить, как меняется ответ

**Чекпоинт:** можете за 5 минут объяснить неспециалисту, чем нейросеть отличается от программы с правилами и почему LLM иногда «выдумывает».

---

## Этап 1. Python — 90–120 часов (9–12 недель)

**Цель:** уверенно писать код для работы с данными.

**Недели 1–2. Основы языка (~20 ч)**
- Переменные, типы (числа, строки, булевы), ввод/вывод
- Условия if/elif/else, циклы for и while
- Практика: минимум 40–50 мелких задач на тренажёре (Stepik «Поколение Python»)

**Недели 3–4. Структуры данных и функции (~20 ч)**
- Списки, кортежи, словари, множества; срезы; вложенные структуры
- Функции: аргументы, возврат значений; область видимости
- Практика: задачи на обработку списков и словарей (частотный словарь текста, фильтрация данных)

**Недели 5–6. Работа с реальным миром (~20 ч)**
- Чтение/запись файлов (txt, CSV, JSON)
- Обработка ошибок try/except
- Установка библиотек, работа в Google Colab / Jupyter: ячейки, вывод, графики
- Мини-проект: скрипт, который читает CSV с любыми данными и выводит статистику

**Недели 7–9. NumPy и Pandas (~30 ч)**
- NumPy: массивы, операции над векторами и матрицами, индексация
- Pandas: DataFrame, чтение файлов, фильтрация, groupby, объединение таблиц, пропуски
- Matplotlib: линейные графики, гистограммы, scatter
- Практика: курсы Kaggle Learn «Pandas» и «Data Visualization»

**Недели 10–12. Закрепляющий проект (~20–30 ч)**
- Выбрать свои данные (расходы, тренировки, рабочая таблица — что угодно личное)
- Полный цикл: загрузка → очистка → анализ → 5–7 графиков → выводы текстом
- Оформить как ноутбук, который не стыдно показать

**Чекпоинт:** берёте незнакомый CSV на 10 000 строк и за час без подсказок получаете из него осмысленные ответы и графики.

## Этап 2. Математика — 70–100 часов (параллельно, по 3–4 ч/нед в течение этапов 1 и 4)

**Цель:** интуитивное понимание трёх китов: линейная алгебра, производные, вероятность.

**Блок А. Линейная алгебра (~30 ч)**
- Недели 1–2: векторы, сложение, умножение на число, скалярное произведение, длина вектора, косинусное сходство (это основа поиска по смыслу!) — 3Blue1Brown Essence of Linear Algebra, серии 1–3 + задачи на Khan Academy
- Недели 3–4: матрицы как преобразования, умножение матриц — 3B1B серии 4–7
- Неделя 5: практика в NumPy — каждый концепт воспроизвести кодом (перемножить матрицы вручную и через np.dot, посчитать косинусное сходство двух векторов)

**Блок Б. Анализ (~20 ч)**
- Недели 1–2: производная как наклон и скорость изменения — 3B1B Essence of Calculus, серии 1–4
- Неделя 3: частные производные, градиент как направление наибольшего роста
- Неделя 4: градиентный спуск — написать на Python поиск минимума параболы (10 строк кода), это «ага-момент» всего машинного обучения

**Блок В. Вероятность и статистика (~25–35 ч)**
- Недели 1–2: вероятность, условная вероятность, теорема Байеса на бытовых примерах (медицинские тесты)
- Недели 3–4: случайные величины, нормальное распределение, среднее/медиана/дисперсия
- Неделя 5: корреляция и её ловушки; симуляции в NumPy (бросить монетку 10 000 раз кодом, увидеть закон больших чисел своими глазами)
- Ресурс: Khan Academy «Статистика и вероятность» + хендбук ШАД для сверки

**Чекпоинт:** понимаете фразу «модель минимизирует функцию потерь градиентным спуском в пространстве параметров» пословно и можете нарисовать картинку к ней.

## Этап 3. Данные и SQL — 40–60 часов (4–6 недель)

**Недели 1–2. SQL-база (~20 ч)**
- SELECT, WHERE, ORDER BY, LIMIT; агрегаты COUNT/SUM/AVG; GROUP BY и HAVING
- Тренажёр: Stepik «Интерактивный тренажёр по SQL» — решить 60–80 задач
- Понять устройство реляционной БД: таблицы, первичные и внешние ключи

**Неделя 3. JOIN и подзапросы (~10 ч)**
- INNER/LEFT JOIN на практике, объединение 2–3 таблиц
- Подзапросы, CTE (WITH) — на базовом уровне

**Неделя 4. Данные в бою (~10 ч)**
- SQLite из Python: загрузить CSV в базу, делать запросы из кода
- Очистка данных в Pandas: пропуски, дубликаты, выбросы, приведение типов
- Форматы: JSON (важно для API), Excel

**Недели 5–6. Векторные БД + проект (~10–20 ч)**
- Концепция: текст → эмбеддинг → поиск ближайших векторов. Поставить Chroma, загрузить 20–30 своих текстов, сделать поиск по смыслу (по туториалу, 2–3 вечера)
- Проект: открытый датасет с Kaggle → SQLite → 10 осмысленных SQL-запросов → очистка в Pandas → выводы

**Чекпоинт:** можете достать данные из базы, соединив три таблицы, и объяснить на пальцах, как работает поиск «по смыслу», а не по словам.

## Этап 4. Классическое машинное обучение — 100–140 часов (10–14 недель)

**Недели 1–3. Первая модель до винтика (~30 ч)**
- Постановка задачи обучения с учителем; признаки и целевая переменная
- Линейная регрессия: как устроена, функция потерь MSE, обучение градиентным спуском
- Логистическая регрессия для классификации
- Курс: Andrew Ng ML Specialization, курс 1
- Практика: обучить обе модели в scikit-learn на игрушечных данных + один раз написать линейную регрессию руками на NumPy

**Недели 4–5. Главные концепции качества (~20 ч)**
- Переобучение и недообучение — центральная идея всего ML
- Train/test split, кросс-валидация
- Метрики: accuracy, precision, recall, F1, ROC-AUC; когда какая (почему accuracy обманывает на редких классах)
- Практика: намеренно переобучить модель и увидеть это на графиках

**Недели 6–8. Арсенал моделей (~30 ч)**
- Деревья решений: как строятся, чем хороши и плохи
- Случайный лес и градиентный бустинг (XGBoost/LightGBM на уровне применения)
- kNN, наивный Байес — обзорно
- Подготовка признаков: кодирование категорий, масштабирование
- Курс: Andrew Ng курс 2 / mlcourse.ai темы 3–7

**Недели 9–10. Обучение без учителя (~15 ч)**
- Кластеризация k-means; снижение размерности PCA (связка с линейной алгеброй!)
- Практика: кластеризовать клиентов/тексты, визуализировать

**Недели 11–14. Боевые проекты (~25–45 ч)**
- Kaggle Titanic: пройти полный цикл, добиться результата выше базового
- Второе соревнование (House Prices) или свой датасет
- Разобрать 2–3 чужих решения на Kaggle — читать чужой код невероятно полезно

**Чекпоинт:** на новых табличных данных самостоятельно строите пайплайн от очистки до сравнения 3+ моделей с честной оценкой и можете объяснить, почему выбрали такую метрику.

## Этап 5. Глубокое обучение и LLM — 100–140 часов (10–14 недель)

**Недели 1–3. Нейросети с нуля (~30 ч)**
- Нейрон, слои, функции активации; прямой проход
- Обратное распространение ошибки — интуитивно + Karpathy «micrograd» (первое видео Zero to Hero): построить автоград на 100 строк вместе с ним
- 3Blue1Brown серия про нейросети — параллельно для визуальной интуиции

**Недели 4–5. PyTorch (~20 ч)**
- Тензоры, автоматическое дифференцирование, цикл обучения
- Обучить полносвязную сеть на MNIST (рукописные цифры) — «hello world» глубокого обучения
- Осознать: цикл обучения везде один и тот же

**Недели 6–8. Путь к трансформеру (~30 ч)**
- Эмбеддинги слов: почему «король − мужчина + женщина ≈ королева»
- Языковое моделирование: предсказание следующего токена
- Karpathy Zero to Hero: makemore (части 1–2 минимум), при силах — больше
- «The Illustrated Transformer» + видео 3B1B про attention: механизм внимания на интуитивном уровне

**Недели 9–10. Как делают LLM (~15 ч)**
- Пайплайн: предобучение → SFT (дообучение на инструкциях) → RLHF
- Токенизация: почему модель «видит» текст кусочками и что из этого следует
- Ограничения: галлюцинации, окно контекста, дата отсечки — теперь уже с пониманием причин
- Видео Karpathy «Intro to Large Language Models» (1 час, лучший обзор)

**Недели 11–14. Практика с готовыми моделями (~25–45 ч)**
- Hugging Face NLP Course, главы 1–4: pipeline, загрузка моделей, дообучение классификатора
- Проект: дообучить готовую модель на своей задаче (классификация отзывов/писем) ИЛИ пройти nanoGPT у Karpathy

**Чекпоинт:** можете нарисовать схему «что происходит с моим сообщением внутри LLM от токенизации до генерации ответа» и объяснить каждый блок.

## Этап 6. Прикладное использование — 80–120 часов (8–12 недель)

**Недели 1–2. Промпт-инжиниринг системно (~15 ч)**
- Курс по промптингу в документации Anthropic + DeepLearning.AI «ChatGPT Prompt Engineering for Developers»
- Техники: роль и контекст, few-shot примеры, цепочка рассуждений, структурированный вывод (JSON/XML), декомпозиция задач
- Практика: взять 5 своих реальных задач и довести промпты до стабильного качества

**Недели 3–4. API (~15 ч)**
- Запросы к Anthropic/OpenAI API из Python: сообщения, system prompt, temperature, max_tokens
- Токены и стоимость: посчитать цену своих сценариев
- Мини-проект: скрипт, прогоняющий LLM по 100 текстам (классификация, суммаризация)

**Недели 5–7. RAG — главная прикладная техника (~25 ч)**
- Архитектура: документы → нарезка на куски → эмбеддинги → векторная БД → поиск → ответ с контекстом
- Собрать RAG по туториалу на своих документах (Chroma + API)
- Улучшение: размер кусков, количество результатов, промпт; понять, где RAG ломается
- Курс: DeepLearning.AI «Building Applications with Vector Databases» / «LangChain: Chat with Your Data»

**Недели 8–9. Агенты и инструменты (~15 ч)**
- Function calling / tool use: как модель вызывает функции
- Собрать простого агента: LLM + 2–3 инструмента (поиск, калькулятор, ваша функция)
- Понять цикл агента: план → действие → наблюдение → повтор

**Недели 10–12. Итоговый проект (~20–40 ч)**
- Один серьёзный проект под свою жизнь/работу: чат-бот по своим документам с источниками, автоматизация разбора писем/документов, телеграм-бот с LLM
- Довести до состояния «пользуюсь сам каждую неделю»
- Дополнительно: локальные модели через Ollama, основы оценки качества (свой мини-бенчмарк из 20 примеров)

**Чекпоинт:** у вас есть работающий ИИ-инструмент, который экономит вам часы, и вы понимаете каждую его строчку.
