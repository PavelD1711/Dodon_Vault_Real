# 📚 Методология

Правила и определения, по которым мы ведём проекты, цели, задачи и всё остальное в этом vault.

## Правило работы

- Каждое правило = отдельный файл в этой папке
- Файлы нумеруются: `01-...`, `02-...` — порядок чтения
- Изменения — через обсуждение Павел ↔ Pablo, потом commit
- Если правило устарело — не удаляем, а помечаем `status: deprecated` и пишем что вместо него
